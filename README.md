# 装备收集图鉴（GlamourBook）

FFXIV Dalamud 插件：可搜索的装备收集图鉴，一站式查看装备来源与拥有情况。

## 功能

- **全装备图鉴**：浏览全部可幻化装备，显示背包 / 投影台 / 雇员 / 收藏柜的拥有情况
- **来源查询**：兑换、商店、制作、采集、钓鱼、副本掉落、任务奖励、成就奖励等
- **雇员缓存**：按雇员分别记录，打开雇员背包后自动更新
- **可收藏装备统计**：列出能放进收藏柜的装备，支持「套装 / 单件」筛选
- **试穿相关**：投影模板导入试穿室、导入当前装备（含幻化与染色）、随机试穿、一键皇帝
- **愿望单与掉落提醒**：宝箱出现或装备进包时，用游戏原生信息框 + 音效提醒

## 安装

在 Dalamud 设置 → 插件仓库中，添加以下地址：
https://showshoway1.github.io/glamourbook-repo/pluginmaster.json

保存后打开插件列表，搜索「装备收集图鉴」并安装。

## 使用

游戏内输入 `/glamour` 打开主界面。

- 右键主界面可调整透明度、每页数量、DTR 显示等
- 「其他」菜单里有扫描附近玩家、导出试穿室、可收藏装备统计

## 说明

- 需要 Dalamud API 15
- 不收集任何个人信息，不联网（可选的查价功能除外）
- 数据全部来自本地游戏数据，无需额外前置插件
